# Караван: компактна серверна частина

Перший онлайн-модуль зберігає лише реєстрацію та **останній знімок ресурсів**.
Основна гра залишається офлайн. Клієнт D7A для Android/браузера підключений через необов’язковий HTTPS endpoint; див. інструкцію нижче.
Графіка, вагони, екіпаж, повні збереження й історія ігрових дій на сервер не передаються.

## Дані й навантаження

- Один запис на гравця: випадковий ID, нікнейм, SHA-256 відбиток особистого
  коду, метал, паливо, припаси, їх сума, версія та три службові часові позначки.
- Особистий код генерується з 32 випадкових байтів, видається лише при реєстрації.
  Це код доступу, а не короткий PIN. Зберігайте його приватно; без пошти автоматичного
  відновлення в цій версії немає. Нікнейм сам по собі права входу не дає.
- Знімок ресурсів змінюється не частіше разу на 60 секунд. Повтор такого самого
  знімка не створює записів і не збільшує версію. Старі версії відхиляються.
- Таблиця: максимум 100 рядків, чотири індекси сортування, кеш 30 секунд,
  HTTP ETag/304. Вебсторінка показує 50 рядків і оновлюється вручну.
- Без фонового ігрового циклу, WebSocket, cron, Redis або постійного опитування бази.
- До 10 000 гравців; максимум 100 реєстрацій на добу сумарно та 5/годину
  з однієї адреси. Загальне обмеження — 120 запитів/хвилину з адреси.
  Лічильники адрес лише в оперативній пам'яті, максимум 2048 записів.
- SQLite обмежена 64 МіБ. Під час повторного встановлення зберігається лише
  **одна попередня копія** до 64 МіБ, без накопичення архівів. Під час заміни
  копії можливий ще один тимчасовий файл до 64 МіБ. Це ліміти, а не резервування місця.
- Окрема служба: один процес, до 16 одночасних запитів, MemoryMax=128M,
  CPUQuota=25% одного ядра, TasksMax=32, Nice=10. Це верхні межі;
  фактичне споживання на Oracle потрібно виміряти після запуску.
- У тесті 1000 вигаданих профілів займають менше 2 МіБ. Це не вимірювання VM.

Рейтинг **тестовий, за даними клієнта**. Сервер перевіряє формат, діапазони,
право зміни профілю й версії, але не доводить чесність здобуття ресурсів офлайн.
Сума трьох ресурсів — початкове сортування; є окремі рейтинги за кожним ресурсом.

## Перший запуск на Ubuntu

Потрібні Python 3.11+, python3-venv, Git, systemd та наявне sudo без пароля
користувача ubuntu. Зберігаємо лише серверні файли, без ігрових зображень:

```bash
git clone --depth=1 --filter=blob:none --sparse https://github.com/mavkaoblik-hub/fantastic-lamp.git /home/ubuntu/caravan-source &&
git -C /home/ubuntu/caravan-source sparse-checkout set server &&
bash /home/ubuntu/caravan-source/server/install.sh
```

Якщо папка вже існує, clone зупиниться; наявні файли не перезаписуються.
Інсталятор відмовляється змінювати іншу службу з тим самим ім'ям або зайнятий порт.
Жодні наявні caravan-backup.timer чи сторонні ігрові бази не змінюються.

Після успіху **у браузері на VM**: http://127.0.0.1:8770/ — таблиця лідерів.
Спочатку вона порожня. Перевірка:

```bash
systemctl is-active caravan-lite.service
curl --noproxy '*' --fail --max-time 5 http://127.0.0.1:8770/health
```

Зупинка/запуск: окремий рядок «Караван — таблиця лідерів» у панелі керування
VM (оновіть MAVKA-SYNC-SERVER). Режими паузи МАВКА стан гри не змінюють.
Збереження: /var/lib/caravan-lite/players.db; єдина попередня копія:
/var/lib/caravan-lite/players.previous.db. Середовище Python окреме, .server-venv.

Оновлення коду сервера:

```bash
git -C /home/ubuntu/caravan-source pull --ff-only &&
bash /home/ubuntu/caravan-source/server/install.sh
```

Установлення перевіряє /health, але автоматичного повернення коду при невдалому
оновленні поки немає. Попередня копія БД не відновлюється автоматично.

## Межа поточного розгортання

Служба слухає тільки 127.0.0.1:8770. Зовнішніх портів/firewall/DNS/тунелів
інсталятор не змінює; HTTPS-адресу не припускає. За замовчуванням Host дозволено localhost/127.0.0.1,
CORS не відкритий, proxy headers вимкнені. Для підключення реальних клієнтів
окремо налаштовуємо перевірену HTTPS-адресу, дозволений Host/Origin і довірений
проксі з коректним клієнтським IP для обмежень частоти. Код входу через
незахищений зовнішній HTTP не передаємо.

## Контракт клієнта

Усі тіла JSON до 2048 байтів. Невідомі поля, дублікати ключів і некоректні значення
відхиляються. Приватні відповіді мають Cache-Control: no-store. Параметри URL
не використовуються для коду доступу. Access logs вимкнені.

| Запит | Дані | Результат |
|---|---|---|
| POST /v1/players | {"nickname":"Капітан"} | Профіль і access_code (лише один раз) |
| GET /v1/me | Authorization: Bearer особистий-код | Приватний профіль і revision |
| PUT /v1/resources | Той самий заголовок; {"revision":0,"resources":{"metal":210,"fuel":80,"supplies":48}} | Новий профіль/revision і changed |
| GET /v1/leaderboard?sort=total&limit=50 | Без коду; sort=total/metal/fuel/supplies, limit=1..100 | Публічні нікнейми й ресурси |

Нікнейм: 3–24 символи, літери/цифри/пробіл/_/-, NFKC нормалізація,
унікальність без урахування регістру. Ресурси: цілі числа 0..1 000 000 000,
без bool/дробів. Клієнт має округлювати свої поточні показники перед надсиланням.
409 revision_conflict: прочитати /v1/me та вирішити, який знімок актуальний,
не перезаписувати мовчки стан іншого пристрою. 429: дотримуватися Retry-After.
Після втрати відповіді можна повторити той самий знімок з тією самою revision.
Старі збереження гри не потрібно завантажувати на сервер.

## Перевірки

```bash
python3 -m pip install -r server/requirements.txt httpx==0.28.1
python3 -m unittest server.test_caravan -v
```

Перевірки використовують тимчасові SQLite-файли та вигаданих гравців.
Не звертаються до Oracle чи особистих збережень. Офіційна довідка:
[FastAPI lifespan](https://fastapi.tiangolo.com/advanced/events/),
[Uvicorn limits](https://uvicorn.dev/settings/#resource-limits),
[Python secrets](https://docs.python.org/3/library/secrets.html),
[SQLite max_page_count](https://www.sqlite.org/pragma.html#pragma_max_page_count).
# Підключення гри D7A

Додано необов’язкову реєстрацію/вхід і клієнт ресурсних зведень для вебгри та Android.
HTTPS endpoint, `CARAVAN_ALLOWED_ORIGINS`, `CARAVAN_ALLOWED_HOSTS`, правила безпеки,
тести й обмеження описані в [інструкції інтеграції](../docs/CARAVAN_SERVER_SYNC_2026-11-03.md).
За замовчуванням зовнішні origins залишаються заблоковані; wildcard не підтримується.
