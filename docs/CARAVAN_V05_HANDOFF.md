# КАРАВАН — v0.5: виправлення компонування (22.10.2026)

За тестовим скриншотом користувача v0.4 знайдено регресію масштабу: за вузького вікна браузера локомотив і хвостовий вагон обрізалися по краях, а підписи ресурсів стискалися.

## Зміни
- Усунуто примусове мінімальне збільшення 0.84: камера вписує повні габарити поїзда у фактичну ширину канви.
- За масштабу 100% панорамування блокується, якщо поїзд уже повністю поміщається в кадрі; після збільшення працює рух.
- Панель ресурсів у вікнах до 1050px переходить на окремий рядок, з відновленими розмірами цифр і назв.
- Ущільнено компонування на малих висотах; збережено механіки та анімацію v0.4.

## Перевірки
Node `--check`: PASS. Chromium / Playwright PASS на розмірах 1600×900, 752×729, 640×720, 844×390, 1024×768, 670×360; у всіх тестах повний поїзд у кадрі; обробка натискання вагонів, покращення, масштабування, розвідка та початок рейсу працюють; JS помилок немає.

## Важливо
Фактичний ігровий пакет із PNG-файлами та автономним HTML наданий у розмові як `КАРАВАН_v0.5_вихідний_проєкт.zip`. GitHub наразі містить цей handoff, але не повний v0.5 з бінарними ресурсами. Технічний Godot-порт не оновлювався; **APK немає**. Потрібен тест користувача у звичайному браузері Android/ПК.
