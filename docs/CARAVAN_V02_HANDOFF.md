# CARAVAN — підсумок розробки 0.2 (22.10.2026)

У поточній розмові створено **окремий архів графічного прототипу 0.2**, без перезапису версії 0.1 у репозиторії.

## Склад архіву
- `web/`: працююча інтерактивна HTML/Canvas-сцена, окремі PNG-спрайти локомотива, майстерні й житлового вагона, шари паралаксу, стилі, single-file HTML для телефону.
- `godot/`: порт основної сцени Godot 4.x з окремими текстурами (джерела; **APK не зібраний і Godot не протестований**).
- `scripts/build_assets.py`: процедура вирізання спрайтів із концептуального аркуша й підготовки композиційних шарів.
- `tests/smoke_test.py`: перевірка HTML у Chromium.
- `README.md`: тестовий план, обмеження та інструкції.

## Фактичні тести
Перевірено у Chromium: завантаження шести використовуваних зображень; вибір вагона; покращення; розвідку; перехід станцій; панель шарів; альбомне компонування 844×390. JS-помилок не виявлено. Збереження в реальному браузері та APK ще перевіряються окремо.
