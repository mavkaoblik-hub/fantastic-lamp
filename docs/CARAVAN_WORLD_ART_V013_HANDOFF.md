# КАРАВАН — World Art v0.13 (22.10.2026)

## Продовження v0.12
Створено **окремий додатковий набір середовища**, без перезапису робочої гри чи Android-проєкту.

### Нове
- 3 регіони: Попеляста долина, Крижаний перевал, Іржавий каньйон; кожен має 4 PNG-шари 1600×900: sky/far/mid/front, 12 шарів.
- 12 незалежних PNG об'єктів 480×320: 4 перешкоди, 4 знахідки, 4 точки експедицій. Зібрані з графічних деталей попереднього арт-пакета з новими композиціями; це не 12 повністю нових мальованих із нуля моделей.
- 3 нові ефекти × 8 покадрових PNG 256×128: жарини, сніг, сигнал; 24 кадри.
- Маніфест із категоріями, назвами, якорями та параметрами паралаксу, SHA256.
- 3 вже наявні спрайти потяга для демонстраційної сцени.
- Працююче автономне HTML-прев'ю з вибором регіону, об'єктів, стартом/зупинкою руху й ефектами.

### Перевірки
51/51 окремих PNG завантажено (48 ресурсів середовища + 3 повторно використані вагони). Chromium: 1440×900, 844×390, 390×844; навігація по регіонах та об'єктах, старт/стоп, без JavaScript errors. ZIP перевірений на CRC.

### Файли для передачі
У поточній розмові створено:
- `КАРАВАН_СВІТ_v0.13_ТЕСТ.html` — автономна інтерактивна HTML-демонстрація.
- `КАРАВАН_WORLD_ART_v0.13.zip` — PNG-шари, файли об'єктів/ефектів, manifest, README та HTML.
- `КАРАВАН_v0.13_КАТАЛОГ_ОБЄКТІВ.png`, `КАРАВАН_v0.13_ТРИ_РЕГІОНИ.png`.
