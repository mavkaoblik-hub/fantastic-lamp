# КАРАВАН — інтеграція графіки v0.13-C у маршрути й виробництво

**Дата:** 27.10.2026. Візуальний еталон — справжня сцена **v0.12** з оригінальними 103 зображеннями. Нові концепти не замінюють оригінальні вагони, персонажів, назви валют чи іконку завдань.

## Виконано в GitHub і поточній Android-збірці

- `game/v012_restored/art_bridge_v013c.js`: єдиний реєстр відображення **6 станцій, 3 подій і 14 типів приміщень**. Використовує концепти v0.13-C, якщо дійсні бінарні файли пакета присутні; інакше — реальні зображення, які вже лежать у репозиторії, без битих посилань.
- `game/v012_restored/app.js` та `index.html`: ілюстрація обраної станції, картки наступних станцій, ілюстрація події, мініатюра виробничого приміщення у контекстній картці вагона.
- **На самій сцені:** над працюючим вагоном невелика іконка виробництва, над вагоном із готовою партією — іконка підтвердження; при критичному стані локомотива — єдиний попереджувальний значок. Використовуються вже затверджені UI-іконки, розмір не змінюється при масштабуванні двома пальцями.
- `tools/caravan_restore_v012.py` додає **8 наявних стилізованих ілюстрацій локацій** із `game/assets/painterly_v021/assets/locations`; оригінальних 103 PNG/JPG торкатися заборонено.
- Опціональне розміщення нових `game/assets/review_v013c/manifest.json` + 72 перевірених PNG активується тільки після перевірки SHA кожного файла. Доти `art_config_v013c.js` має прапорець false.
- У GitHub тест проходить всі UI-сценарії: журнал, рейси, вибір вагонів, збирання продукції, інциденти, натискання, камеру. В APK 16 затверджених UI PNG + 8 рамок + 8 локацій. **В APK поки немає 72 нових PNG!**

## Вебдемо з повним новим пакетом

В артефактах розмови побудована окрема автономна вебзбірка `CARAVAN_v013C_FULL_ART_PLAYABLE_WEB.zip` із **36 новими унікальними концептами / 72 PNG**. У цій збірці прапорець включення виставлено true лише після перевірки кожної SHA-256. Для відображення справжніх нових зображень вебдемо потрібно розпакувати і відкрити в Chrome (за необхідності через `python -m http.server 8787`).

Умови прийняття:
1. У режимі **МАРШРУТ** видно атмосферні ілюстрації станції, пунктів призначення і поточної події.
2. В картці вагона є тематична ілюстрація відповідного виробничого приміщення; зміна типу вагона змінює прев'ю без дублювання ID ресурсів.
3. На вагоні видно стан виробництва / готового складу, але сама структура та деталізація оригінального вагона лишається.
4. Немає нових дубльованих значків валют та завдань, всі 103 історичні спрайти залишилися.
5. Камера: жест двома пальцями масштабує, один палець переміщує, натискання на вагон відкриває компактне керування.
6. Виробництво, пауза рейсів, одноразове отримання винагород і збереження лишаються функціональними.

## Обмеження

**Актуальна Android APK використовує 8 реальних резервних арт-ресурсів із GitHub, але не 36 нових концептів.** Окрема локальна вебзбірка з новими спрайтами перевірена за структурою, RGBА і SHA-256; браузерна навігація на цьому локальному середовищі заблокована політикою, тому візуальне приймання вебдемо — окремий ручний етап. GitHub браузерний smoke для резервної графіки пройдено.

Раніше створений `tools/caravan_import_artpack_v013c.py` дозволяє безпечно внести наявний ZIP у `game/assets/review_v013c/` з перевіркою SHA, без перезаписування вихідних ресурсів. Після фактичного імпорту та затвердження стилю Android workflow включить ті самі спрайти в APK.

## Наступний пункт

Оцінити UI на фізичному Android 844×390, затвердити відбір із пакета і після цього імпортувати дійсні PNG у GitHub (або відхилити невідповідні концепти), а також додати графічні стани поломок на рівні конкретного вагона після впровадження стану `wagon.condition`. Поточне `state.condition` глобальне для всього потяга — не слід називати його несправністю конкретного вагона.
