# КАРАВАН — звіт і передача v0.3 (22.10.2026)

## Причина переробки
Користувач перевірив графічний прототип v0.2 та надіслав зображення з вузького вікна перегляду ChatGPT. Знайдено проблему масштабування потяга за висотою без врахування фактичної ширини екрана. Враження від сцени погіршували занадто масштабний фон, малі елементи потяга і недосконале компонування UI.

## Що зроблено у v0.3
- Автоматичне вписування трьох модулів у видиму ширину вікна.
- Керування масштабом плюс, мінус, поверненням у режим «Весь потяг».
- Кнопка повного екрана (працює залежно від політик браузера).
- Переоброблений дальній фон із деталізованого фрагмента концепту, зменшено неприродну вертикальну розтяжку.
- Компактніша шапка й UI.
- Вибір вагона підкреслюється делікатними маркерами замість великої рамки.
- Послаблене перекриття колес переднім планом; додано основу рейок.
- Збережено розвідку, ресурси, покращення, зміну станції.
- Експортовано самодостатній HTML і вихідний ZIP у поточній розмові.

## Перевірки
Chromium / Playwright: 1600×900, 1248×725, 844×390. У кожному: 6 із 6 графічних ресурсів завантажено, локомотив і 2 вагони цілком у межах видимої зони; вибір майстерні, покращення, zoom/fit, розвідка, рейс, перемикання шарів — PASS; JS помилки відсутні.

Читання-запис прогресу перевірено тестовою емуляцією localStorage між двома документами. Фактичне оновлення локального file:// в тестовому Chromium не перевірено через системне блокування навігації.

## Обмеження
Немає APK; нативний Godot-порт із архіву залишається експериментальним, стану v0.2 з оновленими фонами. Шари й три вагонні спрайти є окремими PNG, проте ще не розкладені до рівня незалежних коліс, людей та освітлювальних деталей. Для всіх назв станцій поки використовується одна базова сцена.

## Наступне завдання
1. Отримати тестування HTML v0.3 на ПК / телефоні.
2. Підготувати анімовані колеса, фари, паралельні потоки диму й екіпаж окремими ресурсами.
3. Перенести новий adaptive-camera pipeline у Godot, фактично відкрити Godot 4 і зібрати APK.
4. Додати окремі фони для різних станцій.

**Увага:** в GitHub зберігається цей звіт та попередній вихідний код. Повний набір бінарної графіки v0.3 надано через ZIP в актуальній розмові, але не залито до репозиторію.
