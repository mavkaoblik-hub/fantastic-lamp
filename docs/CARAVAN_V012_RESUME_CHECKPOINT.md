- `game/v012_asset_packs/packs_manifest.json` — розміри та SHA256 усіх 11 ZIP. Пакети не містять спрощених геометричних SVG.
- `.github/workflows/build-caravan-automatic.yml` — оновлений конвеєр: SHA256 всіх пакунків → `unzip` до Android assets → перевірка 103 зображень → Gradle assembleDebug → перевірка підпису → Artifact.
- `android/README.md` та документація.

## ПЕРЕВІРИТИ ПЕРЕД ЗЛИТТЯМ ГІЛКИ В MAIN
1. Пакетні ZIP всередині містять `assets/...` та вихідний `index.html/app.js/style.css`. Ці папки повинні бути доступні після розпакування.
2. `node --check web/app.js`.
3. У WebView має відкриватися **`https://appassets.androidplatform.net/assets/game/index.html`**. Уміст вебгри суто локальний.
4. Окремо перевірити показ 844x390, скрол панелей/кнопки й стартові збереження на фізичному Android.
5. Якщо Action не стартує в feature branch (workflow лише `main`), після QA здійснити **fast-forward main**; автоматичний build сам запуститься.
6. Переглянути jobs/logs; **тільки після status=success** вказувати користувачу шлях до APK Artifact.

## СТАН НА МОМЕНТ ЗАПИСУ
Повний source+assets відновлено та зафіксовано у віддаленій feature-гілці. **Ще не заявляти**, що Android APK v0.12 зібраний і випробуваний. Треба пройти QA й отримати successful run. Стабільна попередня main-збірка раннього vertical slice v0.1 збережена.

## Заборони / вимоги
- Репозиторій `Мавка Mobile` **не редагувати**.
- Затверджений стиль — деталізований painterly dieselpunk; не підмінювати малюнки процедурними SVG.
- Зберігати вихідні матеріали і фактичні бінарні файли у GitHub.
- Debug-signing у GitHub може мінятися між раннерами, не гарантувати безвтратного оновлення встановленої версії.
