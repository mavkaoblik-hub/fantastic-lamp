## Перший пріоритет — довести наявне до робочого стану

Підготувати справжні прозорі `PNG/RGBA` для вже затверджених `ui.tasks_open`, `ui.crew`, `ui.map`, `ui.upgrade`, `ui.movement`, `ui.stop`, `ui.confirm`, `ui.cancel`, `ui.warning`, `ui.inventory`, `ui.information`, `ui.workshop`. Витягнути їх **із першоджерел, не перемальовувати**, відокремити від фону й тексту, перевірити краї, пропорції й малі розміри.

У верхній HUD додати **лише існуючі семантичні значки**: `resource.metal`, `resource.fuel`, `resource.food` (наявне alias для ігрових припасів), `status.morale`. Не вигадувати додаткових видів грошей: 5 іконок валют уже існують, але відповідні економічні механіки ще не затверджені/не інтегровані.

## Третій пріоритет — єдина система станів

Кожна функціональна кнопка повинна відрізняти `normal/pressed/selected/disabled` через узгоджені накладки й оформлення. Ресурси й вибір вагонів використовують однакові семантичні ID на всіх екранах. Іконка відкриття завдань — **один файл `ui.tasks_open` на всю гру**; іконка кожної валюти — теж єдина. Стан «отримано» не створює другої іконки того самого завдання, а використовує спільну накладку/бейдж.

## Непорушний художній еталон

Деталізований **painterly dieselpunk** затвердженої v0.12: темний метал, іржа, заклепки, латунь, тепле жовтогаряче світло й синьо-чорні тіні. Жодних випадкових фотореалістичних картинок, нових стилізацій, геометричних «фінальних» вагонів. Кожен новий UI PNG має проходити QA на **реальному кадрі** 1280×576 та горизонтальному Android 844×390. Наявні атласи не змінювати.

## Критерій завершення

1. У реєстрі для всіх активних кнопок та лічильників є єдиний semantic ID, правильний файл, прозорість, контрольна сума, цільовий розмір.
2. В APK справді включені перевірені UI файли, а в браузері немає відсутніх або задвоєних ресурсів.
3. Після інтеграції всі попередні механіки працюють: масштаб двома пальцями, 14 типів вагонів, екіпаж, журнал, маршрути, рішення під час рейсу.
4. На малому екрані HUD не перекривається, графіка читабельна та витримана в затвердженому стилі.

**Статус:** аудит виконано; production-підготовка RGBA, новий арт і інтеграція в APK **ще не виконані**. Документ не є заявою про створені нові іконки.
