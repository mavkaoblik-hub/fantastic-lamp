# КАРАВАН — v0.8 «Рухомий екіпаж» (22.10.2026)

## Вихідна база
Версія 0.7: 8 типів вагонів, два графічні рівні L1/L2, 54 кадри екіпажу, анімаційний фон, дим, рух уліво.

## Нові механіки v0.8
- Три незалежні персонажі (механік Марко, медик Олена, охоронець Данило).
- Вибір персонажа через панель або кліком по спрайту в сцені.
- Призначення місця роботи: локомотив, середній вагон, задній вагон.
- Реальний маршрут до цільової координати: ходьба, досягнення точки, idle/work анімація з прогресом, завершення, відновлення патрулювання.
- Тестовий ресурсний результат: механік / машиніст +12 до стану потяга, медик +10 до моралі, інші +6 металу.
- Живий список станів екіпажу, відсоток виконання, помітка вибраного персонажа, ефекти роботи.
- Оновлена адаптивна панель керування; збережені 8 типів вагонів із перемиканням моделей L1/L2, рух парового потяга, дим, зміна швидкості.
- Самодостатній HTML із PNG у base64 без мережевих залежностей.

## Обмеження
Godot не перевірено, APK не зібраний. Збереження ресурсів/апгрейдів передбачене localStorage, але його реальний restart-тест на Android ще потрібен. Доручення в процесі після перезапуску не відновлюють маршрут. Робота персонажа візуалізована idle-кадрами й процедурними іскрами, а не покадровою повною анімацією ремонту.

**Не плутати** з попередніми v0.1–0.7. Джерело продовження — архів v0.8 у розмові, а не ранній main на GitHub. Бінарні ресурси v0.8 в GitHub ще не завантажені.
