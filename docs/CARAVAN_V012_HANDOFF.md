# КАРАВАН v0.12 — інтеграція графіки та підготовка Android

Дата: 2026-10-22

## Реалізовано
- Об'єднано ігрову сцену v0.9 та ресурси v0.11 (не просто арт-атлас).
- 4 незалежні моделі локомотива L1–L4 зі зміною спрайта в сцені; апгрейд 80 металу + 12 палива.
- 14 типів вагонів (8 попередніх + reactor, kitchen, barracks, greenhouse_plus, salvage, arsenal).
- Додавання нового вагона за 60 металу й відчеплення; до 3 вагонів за локомотивом.
- Кожен конкретний вагон має власні тип, рівень L1/L2 й ID (поліпшення 35 металу).
- Вибір вагонів дотиком, робота екіпажу в першому/другому/третьому вагоні, винагороди відповідно до типу, збереження стану.
- Підготовлений самодостатній HTML та Android Java/WebView проєкт із локальними ресурсами (без INTERNET-дозволу).
- Оновлено GitHub Actions workflow у **ZIP**, версія Android 0.12-test.
