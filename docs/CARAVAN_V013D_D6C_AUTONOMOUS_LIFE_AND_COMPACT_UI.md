# «КАРАВАН: ОСТАННЯ ДОРОГА» — v0.13-D6C

Дата: 28.10.2026. Статус: TESTING; реальний Android потребує тесту.

## Вимога
Під час подорожі екіпаж не стоїть постійно біля верстата. Персонажі самостійно роблять короткі перерви, відпочивають, спілкуються з іншими членами екіпажу, відвідують наявний вагон-кухню або проходяться між доступними вагонами. Рішення залежать від персональної **втоми та самотності**, не створюють ресурсів, XP або зовнішніх виходів на колію.

## Реалізовано
- `crew_autonomy.js`: керована станами модель `travel → visit → return` із соціальними перервами, відпочинком, кухнею та прогулянками. Потреби: втома 0–100, самотність 0–100.
- Вибір перерви — тільки в активному русі. Втома від 43 пріоритетно веде до вільного спального місця; самотність від 54 — до сусіда або кухні, від 65 без доступних партнерів/кухні — до прогулянки. Це стартові тестові пороги.
- Збереження `autoActivity`, `autoCooldown`, `loneliness` у вже існуючому `crewData` (ключ `caravan_v12`). Прогрес відновлюється після перезапуску, а пошкоджені записи нормалізуються до безпечного очікування на борту.
- Під час перерви робоче призначення призупинено, виробництво і професійний досвід не нараховуються. Після повернення персонаж поновлює стару роботу **лише за наявності місця**; інакше безпечно залишається на борту. Спальні місця резервуються від переповнення разом із D5/D6B.
- Людина відображається у **наявних художніх вирізах вагонів**, з активністю `rest/social/care/stroll`; пересування між ними поки позначається переходом між інтер'єрами, без окремої анімації коридору чи проходу через зчеплення.
- Вагон-ресторан як новий тип **ще не доданий**. Для короткого візиту по їжу використовується наявний вагон-кухня, аби не підміняти затверджений художній вагон новими геометричними заглушками.

## Екран
- На всіх розмірах дисплея основна сцена займає практично всю доступну ширину; конструктор / карта / екіпаж / журнал відкриваються праворуч за потреби, через наявні кнопки.
- Зменшено верхній заголовок, упорядковано статистику, зменшено нижню панель і спливаючу картку вагона; існуючі можливості вибору, перетягування камери й pinch доступні.
- Графіка: жодних змін 103 канонічних арт-ресурсів, локомотива, вагонів, іконок або рамок.

## Обмеження
Це перша модель автономних перерв, не повна багатолюдна симуляція з точними маршрутами через проходи, взаємною розмовою та анімаційними атласами коридору. Персонаж відвідує конкретний існуючий вагон; не копіюються ігри інших розробників.

## QA
- Node тести: безпечний рух, тригери потреб, соціальні візити, кухня, збереження, повернення до роботи без подвійних місць.
- Browser smoke: відсутність постійного сайдбару, автоматична перерва в рейсі, відсутність людей на пероні, відновлення після reload.
- Android Actions: перевірка збереження канонічних спрайтів, браузерний контроль та компіляція підписаного debug APK.
- Фізичний Android (844×390 / 1280×576), жести камери, видимість вагонів і прийнятність нового темпу — окремий обов'язковий тест. Статус DONE лише після нього.
