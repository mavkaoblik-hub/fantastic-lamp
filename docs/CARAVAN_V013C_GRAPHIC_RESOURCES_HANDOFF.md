В цьому проході з трьох уже створених 4×3 художніх аркушів підготовлено **36 окремих PNG/RGBA-спрайтів** у двох розмірах (разом **72 PNG**), контрольний аркуш `PREVIEW.jpg`, автономну `gallery.html` та `manifest.json` із SHA-256 кожного результату.

- **12 концептуальних варіантів UI** — кнопки паузи/відновлення, швидкості, картки екіпажу, нагород та маршруту. Це **варіанти**, а не нові канонічні значки; вони не замінюють `ui.pause`, `ui.resume`, `ui.tasks_open`, валюти або вже схвалені зображення.

- **12 ілюстрацій виробничих приміщень** — майстерня, житло, склад, медпункт, теплиця, генератор, переробка брухту, оборонний пост, запаси, стіл навігації, радіозв'язок, вантажний кран. Призначення — картки виробництва, об'єкти подій, декоративні елементи; **не заміна оригінальних художніх вагонів v0.12**.

Результат згенеровано й перевірено у поточному артефакті розмови `CARAVAN_v013C_36_SPRITES_PACK.zip`. Фактичні бінарні PNG **поки що не записані до GitHub**; зберігаються як окремий пакет для перевірки. Тут збережено тільки реєстр ролей і безпечний інструмент для імпорту.

Після появи ZIP у робочій папці репозиторію:

```bash
python tools/caravan_import_artpack_v013c.py CARAVAN_v013C_36_SPRITES_PACK.zip
```
