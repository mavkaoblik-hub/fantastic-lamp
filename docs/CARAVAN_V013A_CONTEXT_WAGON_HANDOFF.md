# КАРАВАН v0.13-A — перший крок управління у дусі Fallout Shelter

**Дата:** 27.10.2026 · Повна модель майбутнього геймплею: [CARAVAN_GAMEPLAY_DIRECTION_V013.md](CARAVAN_GAMEPLAY_DIRECTION_V013.md). Арт-еталон лишається **v0.12**.

## Що фактично в коді

- При натисканні безпосередньо на спрайт вагона після врахування поточної камери замість автоматичного відкриття великого конструктора з’являється **компактна картка** (`#wagonQuick`).
- Картка показує фактичну назву, номер, рівень вагона, призначених туди працівників і **три функціональні кнопки** Марко/Олена/Данило (працює / у черзі / направити).
- Клік на працівника направляє його в обраний вагон через **наявний** `assignCrew()`, а не дублює прогрес, економіку чи нарахування винагород.
- На дотик до персонажа у сцені — режим «обрати персонажа → торкнутися вагона», щоб направити його без величезного меню. Велика панель «Конструктор» лишається доступною за окремою кнопкою **«Деталі та покращення»**.
- Картка закривається, не перехоплює двопальцеві жести за своїми межами і не змінює код `camera.js`.
- Збережено **103 оригінальні художні ресурси сцени**, 16 канонічних UI іконок і 8 тестових рамок, 14 типів вагонів, три персонажі, інциденти, журнал, поточні збереження `caravan_v12`.

## Перевірка

- Browser smoke: натискання на оригінальний спрайт другого вагона після перетворення координат → `#wagonQuick` видно, три кнопки є; закрити/відкрити; призначити Марка → його наявна робота `rear`; pinch двома пальцями й попередній рейс мають працювати.
- [Перший успішний Android workflow](https://github.com/mavkaoblik-hub/fantastic-lamp/actions/runs/40470704456): JS smoke PASS, старі перевірки та компіляція debug APK PASS.
- [Другий workflow зі скріншотом картки](https://github.com/mavkaoblik-hub/fantastic-lamp/actions/runs/40471155000): окрема візуальна перевірка, її успіх слід підтвердити за GitHub Actions.
- Android пристрій і фізичний multitouch ще не перевірені, тому статус **TESTING**.

## Чого НЕ зроблено

Не реалізовані постійні робочі місця, спеціалізації, цикли ресурсів, завантаження/збір виробленої партії, drag-and-drop. Це наступні етапи **S-25** і **S-26** із модельного ТЗ. Важливо не активувати одночасно старі разові винагороди `applyReward` і нові безперервні виплати.

## Ручний приймальний тест

1. Відкрий гру й натисни на другий вагон — повинна з'явитися мала картка з трьома іменами, а не велика панель.
2. Натисни «Марко — НАПРАВИТИ»; перевір рух до дверей і роботу у вагоні.
3. Два пальці розведи/зведи — камера змінює масштаб без повторного призначення.
4. Закрий картку; повторно торкнися вагона. Натисни «Деталі та покращення» й переконайся, що старий конструктор доступний.
5. Перевір після перезапуску всі старі збереження, ресурси, рейси, журнал.

Успішна автоматична збірка **не означає**, що роботу на фізичному Android завершено.
