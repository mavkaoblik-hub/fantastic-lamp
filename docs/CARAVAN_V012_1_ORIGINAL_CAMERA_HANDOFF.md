# КАРАВАН v0.12.1 — оригінальна сцена + керування камерою

**Дата:** 24.10.2026. **Базовий арт:** точна відновлена v0.12 із відео користувача (11 ZIP, 103 графічні ресурси). Жодні художні PNG не замінені й не перерисовані.

## Реалізовано без регресії графіки

- Оригінальний `game/v012_restored/app.js` лишає справжній спрайтовий локомотив L1–L4, 14 типів вагонів, видимі інтер'єри, оригінальні кадри анімації екіпажу, вхід у вагони й черги доручень.
- Окремий чистий `game/v012_restored/camera.js`: увесь потяг **0.78x**, робочий огляд **1.0x**, обраний вагон **1.65x**. Ручний діапазон **0.78–2.15x** з прив'язкою зуму до місця дотику й захистом від виходу за край сцени.
- Керування: панорамування пальцем, масштабування двома пальцями, коліщатком миші, кнопки + / − / ПОТЯГ / ВАГОН.
- Переведено координати вибору зі сцени в світові координати при зумі; клік по намальованому вагону працює при поточному масштабі.
- На самій сцені відображається **номер, назва, рівень обраного вагона та масштаб**. У конструкторі кнопка направляє вже обраного працівника саме в цей вагон, зберігаючи чинний механізм робіт v0.12.
- Відновлення `tools/caravan_restore_v012.py` копіює увесь вихідний арт та окремий `camera.js`, контролюючи SHA-256 ZIP.
- GitHub Actions `CARAVAN v0.12 - Restore original approved train`: відновлення ZIP та всієї сцени, тести геометрії камери, браузерний smoke, фізичне пакування debug Android APK, перевірка підпису.

## Приймання

1. Увесь поїзд повинен лишатись видимим у режимі ПОТЯГ.
2. При РОБОЧИЙ сцена має зберігати ідентичний вигляд оригінальної v0.12 за кольором та співвідношенням сторін.
3. Натискання на другий вагон має відображати «ВАГОН 2», назву, рівень. Зум не повинен плутати вагон з фоном.
4. Призначений працівник має виконати роботу, відвідати двері, зайти, вийти та отримати винагороду **один раз**.
5. Графіка L1–L4, зміна типів вагонів, причеплення й відчеплення повинні залишитись працездатними.
6. Мобільний екран 844×390, двопальцеве наближення та плинність рендеру — вимагають браузерного й окремого фізичного Android тестування.

**Не виконано:** інтеграція системи завдань/ресурсів з геометричної v0.4 в оригінальну v0.12, фінальні Android тести на телефоні, релізний ключ підпису. Тому статус `TESTING`, не `DONE`.

### Критична умова
Забороняється використовувати `web/game.js` для малювання нових геометричних вагонів у фінальній сцені. Він є історичним технічним прототипом. Візуальний еталон — `game/v012_restored/` + `game/v012_asset_packs/`.
