# Перший Android-застосунок «КАРАВАН» — v0.13-alpha1

**Статус станом на 22.10.2026:** готовий офлайн вихідний Android-проєкт із кодом гри v0.12, 103 графічними ресурсами, Java WebView, Gradle і тестовим планом. Локальне збирання APK недоступне без Android SDK. GitHub Actions сценарій є, але APK **не буде зібрано, доки ZIP не потрапить до кореня репозиторію**.

## Встановлення з GitHub Actions (один вихідний ZIP)
1. Завантаж архів [з поточної розмови] `CARAVAN_ANDROID_SOURCE_v013.zip` (8,6 МБ).
2. У GitHub `mavkaoblik-hub/fantastic-lamp`: **Add file → Upload files** і вибери цей ZIP **без розпакування**. Залиш назву точно `CARAVAN_ANDROID_SOURCE_v013.zip`, розташування — корінь репозиторію.
3. **Commit changes**. Workflow [Build CARAVAN Android v0.13 alpha APK](../../actions/workflows/build-caravan-v013-from-zip.yml) запуститься після додавання ZIP (можна запустити й вручну після його появи).
4. Зайди в Actions → run → Artifacts → `CARAVAN-v013-alpha-debug-APK`, розпакуй артефакт та передай `app-debug.apk` на телефон.
5. Перевір тестові сценарії в `ANDROID_QA.md` всередині вихідного ZIP.

## Що є у тестовій збірці
- 4 моделі локомотива L1–L4, 14 типів вагонів, причеплення третього вагона, апгрейди вагонів L1–L2.
- 3 рухомих персонажі з дорученнями, роботою всередині вагонів, візуальним рухом і димом.
- Горизонтальна орієнтація, офлайн без INTERNET-дозволу, локальне збереження.
- Це оригінальна сцена v0.12, а **не нова гра з ресурсами v0.21**. Нові графічні пакети інтегруватимемо після перевірки APK.

## Перевірки
Локально перевірено цілісність ZIP (CRC), 103 графічні ресурси, JavaScript-синтаксис, роботу браузерної сцени Chromium (1440×900, 844×390, 915×412), додавання третього вагона та покращення локомотива — без помилок JavaScript. Завантаження через WebView/доступ до localStorage на реальному Android потребують фізичного тесту.

**Важливо:** сам ZIP передано в чаті, він ще НЕ знаходиться в GitHub. Не плутати workflow зі зібраним APK.
