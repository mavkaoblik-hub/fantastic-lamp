# КАРАВАН — D7A / Живий екіпаж і сенсорний Android (03.11.2026)

**Статус: TESTING.** Аналіз фізичного відео користувача показав завеликі панелі й малопомітне життя екіпажу.

- Перенесені покращення `codex/android-touch-display` з успішної збірки 29 жовтня. 103 оригінальні спрайти і канонічні UI-іконки не замінюються. Нові D7/D7B PNG ще **не** входять до APK.
- Для нової гри стартові потреби персонажів різні: механік працює, медик раніше відчуває самотність, охоронець потребує відпочинку. Вони здійснюють автономні дії на коротких рейсах, поки механік виробляє. Для існуючих сейвів потреби **не перезаписуються**. Пороги та відновлення D6C незмінні.
- `interior_life.js`: плавна позиція між кімнатами для D5 й D6C, 2D-перехід по внутрішній осі на базі оригінальних кадрів ходьби. Зникнення персонажа посеред переходу видалене. Під час короткої перерви його виробництво зупиняється; по завершенні поновлюється лише за вільного місця.
- Автономний стан тепер нормалізується без зайвого переприсвоєння на кожному кадрі, що знижує навантаження WebView. Рух не дублює робочі місця.
- Android: верхній HUD 49 CSS px, нижня панель 52 CSS px. Кнопки лишаються висотою 48 px. На вузьких дисплеях зайві текстові підписи ресурсів приховані. Для недоступного відпочинку і переназначення екіпажу показуються конкретні причини.
- Ця версія **не** має покадрового нового коридорного атласу, збільшеної кількості пасажирів або анімацій реальних розмов за столом — D7A покращує рух на затверджених ресурсах, повна D7 залишається наступним етапом.
