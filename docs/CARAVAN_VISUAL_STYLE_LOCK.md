# КАРАВАН — ЗАТВЕРДЖЕНИЙ ВІЗУАЛЬНИЙ СТАНДАРТ

Дата фіксації: 2026-10-22.

## Критичний відгук користувача
Перші два художні атласи демонструють цільовий напрям: **кінематографічний деталізований painterly dieselpunk / post-apocalyptic 2D**, природна матеріальність іржавої сталі, заклепки, труби, механізми, тепле освітлення, цілісні кадри персонажів, атмосферні руїни.

Окрема demo v0.14 із геометричних SVG-елементів **не відповідає** погодженому стилю. НЕ вважати ці SVG production-ready art; не використовувати як кінцевий набір.

## Основне правило
- Для нових об'єктів потрібні високодеталізовані PNG/RGBA, художньо сумісні з пакетами v0.11–v0.12.
- Один і той самий боковий ракурс, зрозумілі пропорції, підлога/якір, світло та узгоджена палітра.
- Стан: концепт ≠ готовий ізольований спрайт ≠ інтегрований ігровий об'єкт. Ці стани не можна плутати.
- Не показувати ігрові заглушки як фінальний графічний результат. Проходити візуальне QA на реальній сцені для ПК та Android.
- Ресурс у каталозі повинен мати джерело, розмір, alpha канал, точку прив'язки, категорію, стан готовності та відповідну ліцензію/право використання.

## Коригувальний пакет v0.14R
У розмові підготовлено `КАРАВАН_v0.14R_ДЕТАЛІЗОВАНІ_РЕСУРСИ.zip` (10 деталізованих об'єктів середовища, 4 зображення потяга, 6 кадрів екіпажу, мальований фон, manifest + HTML-вітрина) та автономну демонстрацію `КАРАВАН_v0.14R_ВИПРАВЛЕНИЙ_АРТ_ТЕСТ.html`.

Ці PNG **повторно використані з попередніх деталізованих ресурсів v0.11**, деякі вирізки очищені. Не заявляти, що це повністю нові мальовані сцени або вже інтегровано в Android. Графічні краї частини об'єктів ще потребують ретуші.

## Стан GitHub
Цей файл зберігає арт-контракт. **Повний ZIP та його PNG поки не завантажено до GitHub**; зберігаються як артефакти розмови. Для надійного резервного копіювання та продовження робіт потрібно залити бінарну графіку до `game/assets/painterly_v014R/`, а не обмежуватися README або handoff.
