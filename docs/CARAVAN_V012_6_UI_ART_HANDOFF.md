# «КАРАВАН: ОСТАННЯ ДОРОГА» — графічний пакет та HUD v0.12.6

**Дата:** 27.10.2026 · Джерело істини: затверджена сцена v0.12 із 103 історичними ресурсами. Жодних нових вагонів, перерисовок локомотива або підміни стилю.

## 1. Відновлення 16 раніше затверджених значків — готове в GitHub і APK

Джерело: `game/assets/catalog/crops_v1/manifest.json` і відповідні незмінні вирізки. Алгоритм `tools/caravan_alpha_icons.py` перевіряє SHA-256 оригінальної вирізки, виключає написи з нижнього краю, виділяє художній об'єкт, прибирає тонкі рамки та створює PNG/RGBA 128×128.

Підготовлено **12 UI**: `ui.tasks_open`, `ui.map`, `ui.crew`, `ui.inventory`, `ui.upgrade`, `ui.workshop`, `ui.movement`, `ui.stop`, `ui.confirm`, `ui.cancel`, `ui.information`, `ui.warning`. Підготовлено **4 ресурси/стани**: `resource.metal`, `resource.fuel`, `resource.food` (старі `supplies` у геймплеї), `status.morale`. Кожен має один семантичний ID і SHA в `game/assets/ui_alpha_v1/manifest.json`.

Файли: `game/assets/ui_alpha_v1/` та `game/v012_restored/ui_icons.js`. У грі реально використовуються відповідні іконки біля лічильників і кнопок, а не просто копіюються у `assets/`.

## 2. Вісім нових декоративних рамок — дизайн-кандидати у GitHub і APK

`game/assets/ui_frames_v1/`, відтворюваний генератор `tools/caravan_ui_frames.py`:
`hud_resource_slot`, `sidebar_frame`, `journal_card`, `route_card`, `incident_frame`, `wagon_context_frame`, `progress_track`, `status_warning_overlay`.

Всі PNG/RGBA 480×240 із прозорим центром і 9-slice-полями, використані в CSS інтерфейсу. Це **нове декоративне оформлення**, не історичні затверджені ілюстрації. Тому статус до перегляду користувачем — **кандидати**; можна допрацювати без зміни логіки гри.

## 3. Шістнадцять відсутніх функціональних значків — окремий пакет концептів

Виготовлені 16 нових художніх PNG з **унікальними ролями**: журнал, пауза, продовження, зум +/−, фокус вагона, зчепити/відчепити, швидкість +/−, призначення екіпажу, отримане/заблоковане завдання, дорожня подія, заблокований маршрут, збереження. Назви ID визначені у `game/assets/catalog/ui_usage_plan_v1.json` і не дублюють валюти або відкриття завдань.

**Важливо:** нові концепти згенеровано як окремий ZIP-артефакт розмови, але їхні бінарні PNG **ще не завантажені у GitHub та APK**. Вони не позначені як реалізовані в грі. Для включення потрібен один контроль стилю і копіювання в `game/assets/ui_new_v1/` із SHA-маніфестом. Тільки тоді вмикати значки в runtime.

## 4. QA, збереження графіки, збірка

- Автоматично відновлені 103 оригінальні спрайти, перевірені архіви SHA-256.
- Окремо пакуються й тестуються **16 PNG іконок та 8 PNG рамок**.
- `tests/caravan_v012_visual_smoke.cjs` перевіряє наявність кожної з 16 іконок, присутність чотирьох лічильників, завантаження 8 декоративних рамок, їхнє застосування в CSS та доступність модульної панелі при 844×390.
- [GitHub Actions — v0.12.6 Android і тест браузера](https://github.com/mavkaoblik-hub/fantastic-lamp/actions/runs/40468648821).
- Поточний debug APK потребує фізичного Android-тесту; постійний ключ підпису й міграція інсталяції не завершені.

- Видавати прямокутні вирізки із фоном за готову прозору графіку.
- Видавати нові концепти, які не потрапили до GitHub, за інтегровані файли APK.
