# Експедиції v0.14 — ігрові ресурси

12 окремих прозорих SVG об’єктів 480×320 у каталозі `game/assets/expedition_v014`.

Всі SVG — **вихідні ігрові ресурси**, а не лише опис. Маніфест містить ідентифікатори, групи та координати прив’язки. Векторні оригінали можна експортувати у PNG для Android/Godot; частина деталей поки потребує художнього полірування.

**Не інтегровано в основну гру v0.12.** Окремий пакет у чаті містить також растрові PNG і тестову HTML-галерею. Мальований AI-концепт (окремий референс) у цей Git-коміт не включено.

Наступне завдання: з'єднати появу об'єктів із експедиціями; зробити клікабельні колізії, збір ресурсів і місії ремонту.
