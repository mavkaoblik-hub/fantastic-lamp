# КАРАВАН — затверджені арт-ресурси від 23.10.2026

Це **чотири оригінальні PNG-атласи**, надані користувачем як затверджений художній стандарт:

- `approved_wagons.png` — 8 нових вагонів та їхні модулі.
- `approved_tasks_actions.png` — іконки завдань, дій та UI.
- `approved_currencies_resources_statuses.png` — валюти, ресурси та статуси.
- `approved_locomotive_upgrades.png` — апгрейди локомотива й обладнання.

Візуальний стандарт: високодеталізований мальований дизельпанк, іржава темна сталь, латунь, тепле бурштинове освітлення, синьо-чорні тіні. Не замінювати простими SVG чи пласкими заглушками.

Оригінальні PNG збережено **байт у байт** як послідовні бінарні частини через ліміт передачі GitHub. Для відновлення й автоматичної перевірки довжини та SHA-256:
```
python3 game/assets/approved_style_20261023/reassemble.py
```
Відновлені оригінали: `game/assets/approved_style_20261023/restored/`.

Статус: затверджені *вихідні художні атласи*, **не** вирізані прозорі ігрові спрайти. Для інтеграції потрібно витягнути окремі елементи, очистити фон, створити однакові масштаби та хітбокси. Оригінали залишаються незмінними. Репозиторій «Мавка Mobile» не змінювати.
