# CARAVAN v0.12 authoritative painterly sprite archive

11 genuine ZIP resource packs containing **103 unique graphical assets** (PNG/JPG) and the source HTML/JS/CSS. Each pack hash is listed in `packs_manifest.json`; GitHub Actions validates SHA-256 and unpacks them for the offline Android APK. They are binary art archives committed to Git, not placeholder SVGs. Source gameplay lives in `web/index.html`, `web/app.js` and `web/style.css`.

Original side-facing train/crew sprites approved; no changes to Mavka Mobile. Do not silently replace them with generated geometry.
