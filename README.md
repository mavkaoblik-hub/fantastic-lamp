# КАРАВАН: Остання дорога — Vertical Slice 0.1

**Статус:** перший інтерактивний технічний прототип, не завершена гра й не готовий APK.

## Що є у комплекті

- `web/` — незалежний браузерний прототип із детально промальованою 2D-сценою, рухомим потягом, станцією, анімованими персонажами, ресурсами та розвитком модулів. Має підтримку дотиків, клавіш, локального збереження та PWA (за HTTPS).
- `godot/` — вихідний проєкт Godot 4.x, підготовлений для Android. Сцена намальована ігровим кодом, а не великим нерухомим зображенням. У ній доступні ресурсна економіка, вибір вагонів, покращення, експедиції, рух, локальне збереження.
- `tests/browser_smoke.cjs` — базовий автоматичний тест логіки браузерної версії.
- `web/assets/concept_cover.png` та `godot/assets/concept_cover.png` — концепт використовується **виключно як заставка**, а не як інтерактивна сцена.

## Тест на телефоні — швидко, без APK

1. Візьміть окремий файл `КАРАВАН_тест_на_телефоні.html` (видається разом з архівом).
2. Перенесіть його на Android через USB, Telegram або Google Drive.
3. Відкрийте файл браузером, який дозволяє відкривати локальний HTML (наприклад, Chrome із файлового менеджера, якщо система це підтримує).
4. Поверніть телефон у горизонтальне положення.
5. Натисніть **РОЗПОЧАТИ ЕКСПЕДИЦІЮ**. Спробуйте **ДОСЛІДИТИ**, **В ДОРОГУ**, торкніться вагонів, покращіть один модуль.

Якщо системний браузер Android блокує запуск локальних HTML-файлів, відкрийте папку `web` через простий локальний HTTP-сервер або розмістіть її на GitHub Pages/HTTPS. PWA-режим (встановлення ярлика) працює за HTTPS.

## Тест нативної сцени в Godot на Windows

1. Установіть редактор Godot 4.4+ (стандартний, без .NET).
2. У Godot виберіть **Import** та відкрийте `godot/project.godot`.
3. Натисніть **F6/F5** для запуску; якщо редактор потребує імпорту ресурсів, дозвольте йому завершитися.
4. Для Android установіть Android SDK, JDK 17 та шаблони експорту для тієї самої версії Godot.
5. У **Project → Export** додайте/перевірте пресет Android, задайтe debug keystore, створіть **APK** і встановіть на смартфон.

Офіційні інструкції Godot: https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_android.html

## Керування

**На мобільному:** дотик до вагона — вибір; перетягування — зміщення камери; кнопки праворуч — зміна огляду; нижні кнопки — дослідити/поїхати.

**На ПК у браузері:** перетягування мишею, ←/→ для зміщення камери, `Space` для рейсу.

## Механіка цього прототипу

- Перша станція, п'ять назв локацій, циклічні короткі рейси по 17 секунд.
- Метал, паливо, припаси, екіпаж.
- Одноразова розвідка кожної станції дає ресурси.
- Три інтерактивні модулі вагона; прокачування рівнів 1–5 витрачає метал.
- Майстерня зменшує витрати палива; житловий вагон зменшує витрати припасів; склад підвищує здобич із розвідки.
- На браузері стан зберігається в `localStorage`, в Godot — `user://caravan_save_v1.json`.

## Що ще НЕ готове

- Немає повноцінних 3D-моделей, Blender-складових, професійних анімацій, боїв, сюжету або карти експедицій.
- Не здійснювалося фактичне відкриття проєкту в Godot/експорт APK в цьому середовищі (Godot та Android SDK відсутні).
- Браузерний JS пройшов перевірку синтаксису та smoke-тест на моделі Canvas/DOM, але не повноцінний графічний Android-тест.
- Баланс ресурсів і прогресу є демонстраційним, не фінальним.

Це **доказ механіки та початкового ігрового вигляду**, а не фінальний арт-еталон чи реліз для Google Play. Не плутати заставку з відтвореною ігровою графікою.
